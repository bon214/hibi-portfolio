# カラー／モノクロのコレクション切り替え

## 要件

- カラー、モノクロをそれぞれ約20点掲載し、別の作品群として鑑賞する。
- 常に操作できるボタンで切り替え、背景・文字・罫線・操作部・ダイアログの配色を連動する。
- カラーは温かい紙色、モノクロは黒に近い無彩色と少し抑えた白文字を使用する。これは試作のデザイン判断であり、写真家本人のステートメントではない。
- 写真の色や構図には加工を加えない。投稿に含まれる白い枠もそのまま維持する。
- 写真を一枚ずつ大きく見る縦スクロール、作品一覧、拡大表示を維持する。
- 無料の静的サイト構成を維持する。管理画面・外部実行時依存は追加しない。

## 実装

`data/works.js`は`collections`のメタ情報と、`collection: 'color' | 'mono'`を持つ作品配列を保持する。配列内の各コレクションの順が掲載順。目標枚数は`targetCount: 20`に記録するが、実際の掲載数は作品データから算出する。足りない点数を複製や生成画像で埋めない。

選択中の作品群だけをDOMに構築し、サムネイルと閲覧用画像を必要に応じて読み込む。詳細画像のキャッシュは4点まで。画面下部の切り替え操作のために余白を確保し、停止時の写真や操作説明に重ねない。

2026-10-26、切り替え操作のデザインを文字と細い下線に変更。囲み枠・補助見出し・丸印・区切り線を外し、選択中の文字色と1pxの下線で状態を示す。下線は短い伸縮とフェードで切り替わり、動きを減らす設定では停止する。各ボタンの操作範囲は76 × 48pxを確保し、キーボードのフォーカス枠も維持。1280 × 720と390 × 844で両配色の表示・選択・写真との余白を確認し、TabとEnterによる切り替えも確認した。

URLは`#collection=mono&photo=固定ID`の形式。既存の`#photo=hibi-2025-03`などのURLは引き続き有効で、写真IDから作品群を判断する。各作品群の最終鑑賞位置と一覧の位置をページ内で記憶する。ブラウザの履歴ではURLの作品群・写真・表示形式を復元する。

## 素材の現状

- カラー：公開済みの5点を維持。約20点までの追加選定・元画像が必要。
- モノクロ：指定された[@hibi_mono](https://www.instagram.com/hibi_mono/)の公開一覧で12投稿を確認。プロフィールに`@hibigraph116 Monochrome`と記載されていることを確認した。各投稿へのURLは作品データの`source`に保存する。
- 個別投稿はInstagramの登録・ログイン案内で閲覧が止まる。公開一覧の長辺640pxの画像だけを取得し、試作用として使用する。原寸取得・高解像度画像の確認はできていない。
- 試作用は長辺400pxと640pxのWebPにし、拡大生成・クロップ・色調変更をしていない。モノクロアカウントの画像にわずかな色味があっても、そのまま維持する。
- モノクロ12点は`selectionStatus: 'preview'`で、最終選定や公開品質の承認を意味しない。5点＋12点で各20点の掲載完了を意味しない。

## 検査と公開条件

`npm run check:preview`は素材の参照・実寸法・ID・コレクション所属・容量を検査する。`npm run check`では試作用素材を許可せず、本番への混入を防ぐ。

本公開前に、カラー／モノクロ各20点程度の選定と元画像を受領し、元比率で800・1400・2200pxの閲覧コピーとサムネイルを生成する。固定IDを保って参照・寸法を更新し、`selectionStatus`を確認済みの公開選定へ変更する。通常検査、ブラウザ確認、公開ファイル照合を経て`main`に反映する。

## 試作の確認記録

2026-10-25、ローカルHTTPサーバーで確認。

- 1280 × 720：カラー／モノクロの作品・配色・Instagramリンク・件数が連動。写真上からのネイティブ上下スクロールと写真位置での停止を確認。
- 各作品群の2枚目から切り替え、復帰時にそれぞれ2枚目を表示。履歴の「戻る」でも作品群と写真が一致。
- 一覧表示中の切り替え、一覧からの作品選択、モノクロ配色の拡大表示、拡大中から履歴で一覧へ戻る操作を確認。
- 390 × 844：写真と切り替え操作が重ならず、画像上からのスクロールが可能。横方向のはみ出しなし。
- 320 × 568、844 × 390：最初の写真・スクロール案内・切り替え操作が重ならず、横方向のはみ出しなし。旧形式の写真URLからカラー作品へ正常に遷移。
- `npm run check:preview`と`git diff --check`が成功。公開用の`npm run check`は試作用画像を検出して意図どおり停止する。
