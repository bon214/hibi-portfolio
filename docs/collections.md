# カラー／モノクロのコレクション切り替え

## 要件と掲載状態

2026-10-26、ユーザーの明示依頼に基づき、[カラー @hibigraph116](https://www.instagram.com/hibigraph116/)と[モノクロ @hibi_mono](https://www.instagram.com/hibi_mono/)から各20点、合計40点を選定しました。カラーの展示告知1枚を除外し、写真を掲載対象としています。投稿元と取得画像の記録は[写真の出典と扱い](asset-sources.md)を参照してください。

- カラーとモノクロを常時操作できるボタンで切り替え、背景・文字・罫線・操作部・ダイアログの配色を連動させます。
- カラーは温かい紙色、モノクロは黒に近い無彩色と抑えた白文字を使います。これはサイトのデザイン判断で、写真家本人のステートメントではありません。
- 写真を一枚ずつ大きく見る縦スクロール、作品一覧、拡大表示を維持します。写真の色・構図・作者の白枠・署名は変更しません。
- 無料の静的サイト構成を維持し、管理画面や閲覧時の外部実行依存を追加しません。

## データと操作

`data/works.js`は`collections`のメタ情報と、`collection: 'color' | 'mono'`を持つ40点の作品配列を保持します。同じコレクションに属する作品の配列順が掲載順です。両コレクションの`targetCount`は20で、通常検査で実数との一致を確認します。初期作品はカラーが`hibi-color-c3ka-2gvly8`、モノクロが`hibi-mono-c2htguvpsjj`です。

各作品は`source`に所属アカウントの投稿URLを持ち、`selectionStatus`は`approved`です。これは今回のユーザーによる公開選定指示に基づく状態であり、写真家本人の個別承認を別途取得したという意味ではありません。掲載順は画面上の鑑賞のための編集判断で、作者の正式なシリーズ構成や意図として扱いません。

選択中の作品群だけをDOMに構築し、サムネイルと閲覧用画像を必要に応じて読み込みます。詳細画像のキャッシュは4点までです。画面下部の切り替え操作用の余白を確保し、写真や操作説明と重ねません。

切り替えは文字と細い下線で表現します。囲み枠・補助見出し・丸印・区切り線は使いません。下線は短い伸縮とフェードで切り替わり、動きを減らす設定では停止します。各ボタンの操作範囲とキーボードのフォーカス表示を維持します。

## URLと既存リンク

URLは`#collection=mono&photo=固定ID`の形式です。掲載中のIDを使う`#photo=固定ID`は、写真IDからコレクションを判断します。各作品群の最終鑑賞位置と一覧の位置をページ内で記憶し、ブラウザの履歴では作品群・写真・表示形式を復元します。

初回v1のカラー5点は今回の20点に入れ替えました。削除した旧IDのURLはカラーの先頭へ移動します。旧IDを別作品に再利用しません。モノクロの640px試作12点とWebP 24ファイルも今回の20点に置き換え、試作ファイルを削除しました。

## 閲覧画像

取得JPEGは全40点が幅1440px、高さ1150〜1800pxです。`assets/photos/instagram/`に各4サイズとサムネイル、合計200 WebP・20,611,074 bytesを用意しています。長辺400・800・1400・2200pxを候補とし、取得元の長辺で止めるため拡大生成しません。今回の最大サイズは長辺1440〜1800pxです。

取得JPEGは`assets/reference/instagram/`、生成manifestは`artifacts/instagram-image-manifest.json`に置き、Git管理対象外です。画像の再生成は[更新ガイド](update-guide.md)に従います。

## 検査と公開条件

`npm run check`は40作品・200閲覧画像、固定ID、実画像寸法、容量、コレクションの`targetCount: 20`との一致、各`source`のアカウント所属を検査し、成功しています。`preview`は通常検査で拒否します。`npm run check:preview`は試作時の検査用で、公開合格の代わりにはしません。

今回の40点によるPC・スマートフォン相当の表示、両テーマの切り替え、スクロール、一覧、拡大、直接URL、履歴、キーボード操作の確認を経て、`main`に反映します。GitHub Pagesのデプロイ成功後に`npm run verify:public -- https://bon214.github.io/hibi-portfolio/`で公開ファイルを照合します。公開先と料金条件は既存の無料GitHub Pages構成を継続します。

この文書の時点では今回の更新の最終QA・公開照合は進行中です。公開完了や実端末のタッチ確認を済んだものとして扱いません。検証結果は[検証記録](validation.md)に記録します。
