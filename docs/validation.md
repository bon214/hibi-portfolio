# v1 の確認記録

確認日：2026年10月25日。

## 公開前の品質確認

- 写真を一枚ずつ大きく表示。1280 × 720 の画面では横位置写真を約762 × 508で表示し、元の構図を維持。
- 本人作品の一次出典を確認した5点をv1の選定として使用。架空の作品名・シリーズ・撮影情報・作者のステートメントは追加していない。
- 800 / 1400 / 2200px の長辺別WebPとサムネイルを用意。必要な表示サイズに合わせて選択し、拡大時には最大サイズを使用。
- クロップ・色調変更・回転を行わず、原本のICCプロファイルを引き継ぐ。位置情報を含むEXIFは閲覧コピーに含めない。
- 切り替え先の写真を読み込み終えてから表示。連続操作で古い画像と新しい番号が混ざらないよう、非同期処理の結果を照合。
- 管理画面、外部フォント、解析タグ、外部の実行時依存を使用しない。
